# Kit de marca vouRevisar

Arquivos criados para uso no produto, e-mail e Canva:

- `vourevisar-logo-horizontal.svg`: versão principal para cabeçalho, sidebar aberta, materiais e e-mail.
- `vourevisar-mark.svg`: símbolo quadrado para favicon, app icon, avatar e sidebar recolhida.
- `vourevisar-logo-mono.svg`: versão monocromática para fundos simples ou impressão.

## Direcao visual

A marca preserva a ideia atual de evolução por linha de progresso, mas troca o efeito neon por uma leitura mais limpa. O símbolo combina uma trilha de revisão com subida de desempenho, pensado para comunicar estudo recorrente, confiança e progresso sem parecer uma tela decorativa.

## Cores

- Azul principal: `#2F80FF`
- Azul ciano de apoio: `#28B8D8`
- Verde progresso: `#5E9F3E`
- Texto principal: `#172033`
- Texto secundario: `#617084`

## Canva

Importe os SVGs diretamente no Canva. Se o texto for convertido de forma diferente, use uma fonte sem serifa moderna como Inter, Manrope, Avenir Next ou Montserrat. Mantenha `vou` com peso medio e `Revisar` em peso forte.
