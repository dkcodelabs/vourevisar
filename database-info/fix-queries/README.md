# 🔧 Queries de Correção

Esta pasta contém queries de correção baseadas nos dados reais do banco.

## 📁 Estrutura:

- **`precise-fix.sql`** - Query de correção precisa baseada nos tipos de dados reais
- **`backup-queries.sql`** - Queries de backup antes das correções
- **`validation-queries.sql`** - Queries para validar se as correções funcionaram

## ⚠️ Importante:

Todas as queries desta pasta são baseadas na análise real da estrutura do banco e devem funcionar sem erros de tipo de dados.
